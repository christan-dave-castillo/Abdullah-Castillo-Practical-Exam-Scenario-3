# Milk Tea and Beverage Shop POS

Scenario 3 of the IT415 practical exam. A simple Python/Tkinter desktop POS.

## Run locally

Use Python 3.10 or newer with Tkinter installed, then run from this directory:

```sh
python main.py
```

The initial interface includes six priced products, an order summary, cash
payment controls, and a digital receipt panel. Transaction logic follows in
the next commit.
